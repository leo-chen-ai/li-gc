# 厂家补考勤接口文档

## 1. 接入说明

- 正式服务地址：`https://shanhuai.top`
- 数据格式：`application/json; charset=utf-8`
- 字段命名：camelCase
- `deviceId` 必传，对应序列号。
- 设备必须存在、未删除

## 2. 拉取补考勤任务

### 2.1 接口信息

- 请求方式：`GET`
- 请求地址：`https://shanhuai.top/attendance-jobs`

### 2.2 查询参数

| 参数 | 类型 | 必填 | 默认值 | 说明                                                    |
| --- | --- | --- | --- |---------------------------------------------------------|
| `deviceId` | string | 是 | - | 厂家设备序列号                                          | |
| `update` | integer | 否 | `0` | 秒级时间游标，首次不传或传 `0`，后续传上次响应的 `time` | |

### 2.3 请求示例

```http
GET /attendance-jobs?deviceId=B-DEVICE-001&update=1785897500 HTTP/1.1
Host: shanhuai.top
```

### 2.4 成功响应

```json
{
  "success": true,
  "code": 0,
  "message": "success",
  "time": 1785897600,
  "event": "attendanceJobs",
  "data": [
    {
      "jobId": "3fe80766-9851-4a68-b270-c70ec229597d",
      "messageId": "supplemental-attendance:记录UUID:设备UUID",
      "projectId": "8d68fc5d-d52a-4146-8232-6bd967ce8a40",
      "workerId": "61ad2283-1dd0-4c02-a580-798f971221c4",
      "workerName": "张三",
      "attendanceTime": 1785897600000,
      "direction": "in",
      "photoUrl": "https://example.test/photo.jpg",
      "attemptCount": 1
    }
  ]
}
```

### 2.5 返回字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 请求是否成功 |
| `code` | integer | 业务码，成功为 `0` |
| `message` | string | 响应消息 |
| `time` | integer | 本次任务秒级时间游标，下次请求作为 `update` 传回 |
| `event` | string | 固定为 `attendanceJobs` |
| `data[].jobId` | UUID | 补考勤任务 ID，结果回传时原样传回 |
| `data[].messageId` | string | 幂等消息 ID，同一任务重试时保持不变 |
| `data[].projectId` | UUID | 山淮项目 ID |
| `data[].workerId` | UUID | 山淮人员 ID |
| `data[].workerName` | string | 人员姓名 |
| `data[].attendanceTime` | integer | 补考勤时间，毫秒级时间戳 |
| `data[].direction` | string | `in` 进场、`out` 出场 |
| `data[].photoUrl` | string/null | 考勤照片地址，无照片时为 `null` |
| `data[].attemptCount` | integer | 当前任务被设备领取的次数 |

### 2.6 拉取规则

- 只返回目标设备为当前 `deviceId` 的任务。
- 首次不传 `update`、传空值或传 `0`，返回当前已经到计划时间的任务。
- 后续传上次响应的 `time`，只返回游标之后且已经到计划时间的任务，未来任务不会提前返回。
- 没有待处理任务时，HTTP 状态为 `200`，`data` 返回空数组。
- 重试时 `jobId` 和 `messageId` 不变，`attemptCount` 增加。

## 3. 回传补考勤结果

### 3.1 接口信息

- 请求方式：`POST`
- 请求地址：`https://shanhuai.top/attendance-results`
- 请求头：`Content-Type: application/json`

### 3.2 请求体

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `deviceId` | string/number | 是 | B 厂家设备序列号，必须与领取任务的设备一致 |
| `data` | object/array | 是 | 一条结果对象或结果数组，最多 100 条 |
| `data[].jobId` | UUID | 是 | 拉取接口返回的任务 ID |
| `data[].status` | string/number | 条件必填 | 设备状态，与 `success`、`code` 至少传一个 |
| `data[].success` | boolean | 条件必填 | 是否成功，优先级最高 |
| `data[].code` | string/number | 条件必填 | 设备结果码，`0` 成功，非 `0` 失败 |
| `data[].message` | string | 否 | 设备处理说明 |
| `data[].msg` | string | 否 | `message` 的兼容字段 |
| `data[].time` | string/number | 否 | 设备上报时间，支持秒、毫秒时间戳或 RFC3339 |

### 3.3 单条结果请求示例

```http
POST /attendance-results HTTP/1.1
Host: shanhuai.top
Content-Type: application/json

{
  "deviceId": "B-DEVICE-001",
  "data": {
    "jobId": "3fe80766-9851-4a68-b270-c70ec229597d",
    "success": true,
    "code": 0,
    "message": "补考勤成功",
    "time": 1785897600000
  }
}
```

### 3.4 批量结果请求示例

```json
{
  "deviceId": "B-DEVICE-001",
  "data": [
    {
      "jobId": "3fe80766-9851-4a68-b270-c70ec229597d",
      "status": "processing",
      "code": 0,
      "message": "已受理"
    },
    {
      "jobId": "ed4ef643-06a2-43a2-89ba-d0f123901594",
      "status": "failed",
      "code": 42,
      "message": "照片处理失败"
    }
  ]
}
```

### 3.5 成功响应

```json
{
  "success": true,
  "code": 0,
  "message": "success",
  "time": 1785897600,
  "event": "attendanceResults",
  "data": [
    {
      "jobId": "3fe80766-9851-4a68-b270-c70ec229597d",
      "status": "success"
    }
  ]
}
```

响应中的 `status` 是平台最终生效的标准状态。

### 3.6 状态转换规则

| 厂家传值 | 平台标准状态 | 说明 |
| --- | --- | --- |
| `pending`、`processing`、`accepted` | `accepted` | 考勤机已受理，尚未完成 |
| `success`、`ok`、`0`、`success: true` | `success` | 考勤机处理成功 |
| `failed`、`error`、非零数字、`success: false` | `failed` | 考勤机处理失败 |

## 4. 错误响应

### 4.1 响应格式

```json
{
  "success": false,
  "code": 400,
  "message": "请求参数错误",
  "time": 1785897600,
  "data": [],
  "event": "attendanceJobs"
}
```

结果回传接口发生错误时，`event` 为 `attendanceResults`。

### 4.2 HTTP 状态码

| HTTP 状态码 | 说明 |
| --- | --- |
| `200` | 请求成功或幂等重复回传 |
| `400` | 参数格式错误、缺少必要字段、状态值不支持 |
| `404` | 设备不存在，或任务不存在、不属于当前设备、不可回传 |
| `409` | `deviceId` 存在重复设备绑定 |
| `500` | 服务内部错误 |
