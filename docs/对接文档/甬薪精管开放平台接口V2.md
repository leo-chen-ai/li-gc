## 统一说明  

### 接口调用说明  


1. 所有接口基于http协议 POST请求  
2. 请求地址: url/{URL}
3. 使用application/json格式提交
4. header中必传参数
```
    projectCode String 必填 项目码
    appKey String 必填 分配的appKey
    timestamp String 必填 毫秒时间戳 和正服时间相差必须在10分钟内
    sign String 必填 签名(长度32位，小写), 签名方式: md5(appKey + "&" + appSecret + "&" + timestamp)
```
5. 统一返回格式:
    ```json
    {
        "code":0, // code=0 表示请求成功, 其他值表示请求失败
        "msg":"ok" , // msg 在请求失败时返回错误信息
        "data":{} // data 包含业务数据, 无业务数据时返回null,有业务数据时根据具体接口约定格式返回
    }
    ```
6. AES加密及解密

敏感信息（银行卡号，证件号码等）需要加密传输，请使用 AES 加密,算法说明:

算法密钥=App secret,

编码=UTF8，

加密模式(CipherMode)=CBC，

填充模式(PaddingMode)=PKCS7,

数据块大小(BlockSize)=128，

算法的初始化向量(IV)= 接入密钥 App secret 的前 16 位字符，

加密后的字节数组转为 Base64 字符串，需要加密的字段会在字段备注中添
加‘AES’标记。算法：密文=Base64(AES(info, KEY))

7. 接口访问频率及限制

一个app key帐号，每秒只能通过2个请求，超出该频率返回429错误码
